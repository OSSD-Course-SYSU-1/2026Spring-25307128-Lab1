# 新增功能说明文档：打卡激励型待办管理 App

## 一、功能升级概述

本次开发基于原始 HarmonyOS 待办事项列表编辑工程进行功能扩展。原项目主要实现待办事项的新增、编辑、完成状态切换和删除功能。本次在保留原有功能的基础上，新增了积分奖励、宠物成长、主题切换、主题商店、今日打卡、模拟跨设备投送、搜索排序、优先级、统计面板以及番茄专注等功能。

通过本次扩展，项目由一个基础待办列表应用升级为一个具有激励机制、个性化主题、多设备场景设计和轻量专注功能的待办管理 App。

## 二、原有功能保留情况

本次新增功能开发保留了原项目的基础能力，包括：

1. 点击添加按钮新增待办事项；
2. 点击 Checkbox 切换待办完成状态；
3. 点击编辑按钮修改待办事项内容；
4. 左滑或点击删除按钮删除待办事项；
5. 使用 List 组件展示待办事项列表；
6. 使用 TodoListItem 组件封装单条待办事项。

## 四、新增功能详细说明

### 1. 积分奖励系统

用户完成待办任务后可以获得积分奖励。积分会显示在首页中，并作为宠物成长和主题兑换的基础数据。

实现思路：

- 在首页维护积分状态变量；
- 当用户完成任务时积分增加；
- 当用户取消完成时，可根据逻辑扣减积分；
- 页面根据积分变化自动刷新显示。

### 2. 宠物成长卡片

新增宠物成长区域，根据用户积分显示不同等级的宠物形象和成长状态。

宠物等级设计如下：

| 积分范围 | 宠物等级 |
|---|---|
| 0-49 | Lv.1 学习蛋 🥚 |
| 50-99 | Lv.2 学习幼崽 🐣 |
| 100-199 | Lv.3 努力小猫 🐱 |
| 200-399 | Lv.4 专注小熊 🐻 |
| 400-699 | Lv.5 智慧小狐 🦊 |
| 700 以上 | Lv.6 学习神龙 🐲 |

该功能将待办完成行为与宠物成长结合，提高应用的趣味性和持续使用动力。

### 3. 任务统计面板

首页新增任务统计面板，显示：

- 总任务数；
- 已完成任务数；
- 未完成任务数；
- 完成率。

统计数据根据当前任务列表实时计算，用户新增、完成、取消完成或删除任务后，统计面板会自动更新。

### 4. 主题颜色切换

应用支持多种主题颜色切换，例如蓝色、绿色、紫色、橙色等。切换主题后，页面标题、按钮、标签、卡片等主要 UI 元素会跟随主题变化。

### 5. 主题商店兑换功能

新增主题商店功能，部分主题可以直接使用，部分高级主题需要消耗积分兑换。

示例设计：

- 蓝色主题：免费；
- 绿色主题：免费；
- 紫色主题：50 积分；
- 橙色主题：80 积分；
- 樱花粉主题：120 积分；
- 星空黑主题：200 积分。

当积分不足时，应用会提示用户继续完成任务或打卡获取积分。

### 6. 今日打卡功能

新增“今日打卡”功能，用户点击打卡按钮后可以获得积分奖励，并更新宠物鼓励语。该功能用于模拟习惯养成场景。

### 7. 模拟跨设备投送功能

新增模拟跨设备投送功能。用户可以点击待办事项中的“投送”按钮，选择目标设备，例如手机、平板、智慧屏或电脑。选择设备后，页面显示投送提示，并记录最近一次投送信息。

由于本次作业主要在 DevEco Studio 模拟器环境中完成，缺少真实多设备分布式连接环境，因此本项目采用模拟投送方式实现跨设备交互流程。该功能重点体现 HarmonyOS 多设备协同场景设计思想。

### 8. 搜索功能

首页新增搜索框，用户输入关键词后，待办列表会根据关键词进行筛选，便于在任务数量较多时快速查找目标待办。

### 9. 排序功能

项目新增排序按钮，支持按创建时间、名称、完成状态或优先级等方式对任务进行排序，提升列表管理效率。

### 10. 优先级功能

待办事项支持高、中、低优先级标签。不同优先级通过标签展示，用户可以更直观地区分任务重要程度。

### 11. 删除确认弹窗

为避免误删任务，项目新增删除确认弹窗。用户点击删除后需要确认操作，确认后才会真正删除任务。

### 12. 番茄专注功能

新增轻量版番茄专注功能。用户可以选择某个待办任务进入专注状态，首页宠物卡片会显示当前专注任务。点击“完成专注”后，积分增加，今日番茄数增加。

本功能未使用复杂倒计时，而是以轻量方式模拟番茄 Todo 的专注激励机制，保证功能稳定可运行。

## 八、当前限制与后续优化方向

当前版本主要面向课程作业和模拟器环境完成，仍有以下可优化方向：

1. 当前跨设备投送为模拟实现，后续可接入真实 HarmonyOS 分布式能力；
2. 当前番茄专注为轻量版，后续可加入真实倒计时；
3. 当前数据主要保存在运行状态中，后续可加入本地持久化；
4. 主题商店后续可加入更多主题样式；
5. 宠物成长后续可加入图片资源和动画效果；
6. 可进一步优化大小屏适配和多端协同体验。

## 九、开发总结

本次开发在原始开源 HarmonyOS 待办列表工程基础上进行了较多功能扩展。通过新增积分、宠物成长、主题商店、模拟跨设备投送和番茄专注等功能，项目从简单的列表编辑示例升级为具有激励机制和多设备场景设计的任务管理应用。
